# TypeToll — landing page

Landing page and privacy policy for **TypeToll**, a Chrome extension that adds friction to short-video feeds (YouTube Shorts, Instagram Reels, X): after 5 minutes you wait, then hand-type a sentence to keep going.

- `index.html` — landing page
- `privacy.html` — privacy policy

Published with GitHub Pages: https://mao-glitc.github.io/typetoll/

The extension's source code is **not** included in this repository.
